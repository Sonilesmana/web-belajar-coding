Fitur Lengkap

🔐 Login & Register

Daftar sebagai Guru atau Siswa. Data tersimpan aman di browser (localStorage). Ada akun demo sekali klik.

🎥 Video dari Guru

Guru tambah video YouTube / link MP4. Siswa nonton langsung di dashboard dengan daftar playlist.

🔵 Zoom / Live Class

Guru buat jadwal Zoom (link Zoom / Google Meet). Plus tombol Kelas Live Instan via Jitsi tanpa install.

💬 Live Chat

Chat diskusi kelas realtime antar tab/browser. Otomatis update, tampil nama & peran.

📄 Sharing Materi

Upload & download PDF, DOC, PPT, ZIP, gambar. Cari materi, hapus, dan lihat siapa pengupload.

🚀 Projek Siswa

Hasil web & projek siswa tampil di halaman depan. Siswa submit link demo + GitHub langsung dari dashboard.

📱 Responsif

Bisa dibuka di HP, tablet, laptop. Tanpa server, cukup double-klik index.html.

🚀 Hasil Web & Projek Siswa

Karya nyata siswa — klik Demo untuk lihat langsung, klik Kode untuk lihat source.

Punya karya? Masuk sebagai Siswa → Dashboard → menu 🚀 Projek Siswa → Tambah Projek. Otomatis tampil di sini.

Cara Pakai

  1. Buka file index.html di browser, klik Daftar → pilih peran Guru / Siswa.
  2. Login → otomatis masuk ke Dashboard.
  3. Guru: tambah video, buat jadwal Zoom, upload dokumen. Siswa: nonton, join Zoom, chat, download.
  4. Untuk kelas video langsung: Dashboard → menu Zoom → Mulai Kelas Live.
